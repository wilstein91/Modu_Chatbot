# 카테고리 ↔ 문서 매핑표

> 챗봇은 카테고리를 고른 뒤 **이 표에 연결된 섹션만** 읽고 답한다 (Step 5 근거 조립이 이 표를 그대로 쓴다).
> 경계 규칙: **답에 필요한 핵심 사실이 들어 있는 문서가 속한 카테고리로 보낸다** (질문 속 단어가 아니라 답의 위치).
> 결정: 현준님 (2026-11-03) · 근거는 `.study/DECISIONS.md` Step 2

## 어디에도 연결하지 않은 섹션

- `00` 퍼실의 공지란 (환영 인사), 메인 페이지 목차 — 규정 내용 없음
- `13` 데이터베이스 목록 (FAQ 제목만 나열) — 각 하위 페이지에 내용이 있음
