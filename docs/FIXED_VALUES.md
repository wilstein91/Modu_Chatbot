## 넣지 않은 숫자

- `+1일` (공가 전산 신청 기한, 04·05) — CONFLICTS #3에서 "전일까지, 불가피하면 당일"로 확정해 정답이 아님.
- 일자별 커리큘럼 날짜(03) — 너무 많고 변동 가능. 일정 질문은 답변 규칙으로 "변동 가능" 명시.
