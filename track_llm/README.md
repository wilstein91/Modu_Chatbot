# track_llm — JEV 미사용 버전 (노드 4 방식)

| 파일 (예정) | 하는 일 | 만드는 단계 |
|---|---|---|
| `prompts.py` | 분류 지침(카테고리 정의·헷갈리는 경계·범위 밖·확신도 지침) + 답변 규칙(절차는 번호로, 금지는 규칙 목록으로) | Step 4, 6 |
| `router.py` | 규칙 라우터(기준선) → LLM 라우터(`with_structured_output`), `gate` 노드의 확신도 임계값 | Step 3, 4 |
| `agent.py` | 판정 → 근거 조립 → 답변(도구 호출 루프) → 검증 LangGraph | Step 6, 8 |

비교 기준: 이 버전이 **기준선**이다. `track_jev`는 이 버전과 같은 평가셋·같은 채점기로 잰다.
