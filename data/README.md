# data — 평가셋

`goldenset.json`은 시간 제약으로 **AI가 초안을 쓰고 작성자(Sung, Hyun-Joon)가 채점 정책을 정해 검토**했다. 챗봇에 유리해지지 않도록 챗봇 코드가 없을 때, 구현과 분리된 에이전트가 문서만 보고 작성했다 (REPORT 3항목).

노드 5 요건:
- 문의 10건 이상, 카테고리별 개수 비슷하게 (권장: 카테고리당 8~10건)
- 문항마다 **기대 도구 · 반드시 담을 사실 · 말하면 안 되는 것**
- 문서에 답이 없는 문의 몇 건 (넘기기가 정답) — [docs/CONFLICTS.md](../docs/CONFLICTS.md)의 충돌 주제가 좋은 후보
- 말하면 안 되는 것에는 "문서를 안 읽으면 나오기 쉬운 그럴듯한 오답" (예: 1기 일정, 일반적인 장려금 상식)
- 프롬프트 예시용(`fewshot`)과 평가용(`eval`)을 `split` 칸으로 나눈다

형식 예시 (Step 2에서 확정):

```json
{
  "id": "Q001",
  "split": "eval",
  "question": "병원 다녀오느라 조퇴했는데 공결 되나요?",
  "category": "(Step 2에서 정한 이름)",
  "expected_tools": ["(조회 도구 이름)"],
  "must": ["질병", "진료확인서"],
  "forbid": ["영수증"]
}
```
