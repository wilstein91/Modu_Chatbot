# common — 두 버전이 함께 쓰는 부품

두 버전의 점수 차이가 **판정·검증 방식 차이에서만** 나오도록, 나머지는 여기 한 벌만 둔다.

| 파일 | 하는 일 | 만드는 단계 |
|---|---|---|
| `context.py` | `docs/notion_2기/*.md`를 섹션으로 쪼개고, 카테고리 → 문서 섹션 매핑표(`SECTION_MAP`)로 필요한 부분만 조립 | Step 5 |
| `tools.py` | 근거 조회 도구 (카테고리별 문서 조회, 운영진 이관) — 평가셋의 "기대 도구"와 이름을 맞춘다 | Step 5 |
| `guardrail.py` | 답변 속 숫자·기간·링크가 조립한 근거에 있는지 기계적으로 검사 | Step 7 |
| `evaluate.py` | 분류 지표(정확도·macro F1·혼동 행렬) + 도구 호출 적절성 + 답변 적절성 채점, 모범 답안으로 채점기 검증 | Step 3, 8 |
